# Fortrend Engine

Fortrend Engine is a cross-platform open-source game graphics engine built with C++23 and Vulkan.

## Status

Early development.

Current milestone: project bootstrap.

## Platforms

- Windows
- Linux

## Compilers

- MSVC
- GCC
- Clang

## Current infrastructure

- C++23
- CMake
- CMake Presets
- Ninja
- vcpkg
- GoogleTest
- CTest

## Rendering API

Vulkan.

## Project goals

The project is focused on modern real-time rendering, GPU programming, game graphics architecture and modern C++.
